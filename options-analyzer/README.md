# Options Risk Analyzer — เครื่องมือวิเคราะห์ความเสี่ยงก่อนซื้อออปชั่นหุ้นสหรัฐ

เครื่องมือนี้ช่วยให้ตัดสินใจซื้อ **Call / Put** ด้วยตัวเลขทางสถิติ แทนการเดาจากกราฟอย่างเดียว
พิมพ์ชื่อหุ้น 1 คำสั่ง แล้วจะได้:

1. **ผลตรวจสอบข้อมูล** ทุกครั้งที่รัน ถ้าข้อมูลไม่ผ่าน เครื่องมือจะ *ไม่แสดงผลวิเคราะห์ส่วนนั้น* เพื่อไม่ให้คุณตัดสินใจจากตัวเลขที่ผิด
2. **ภาพรวมหุ้น**: แนวโน้ม (SMA20/50/200), RSI, ความผันผวนจริง (HV), ATR, Beta, Max drawdown, VIX
3. **ความน่าจะเป็นรายสัปดาห์**: หุ้นตัวนี้มีโอกาสขึ้นหรือลงใน 5 วันทำการข้างหน้าเท่าไร และ *สถิตินั้นเชื่อถือได้แค่ไหน*
4. **ข้อมูลออปชั่น**: IV, กรอบราคาที่ตลาดคาด (expected move), ราคา straddle เทียบกับการเคลื่อนไหวจริงในอดีต, skew, Put/Call ratio, วันประกาศงบ
5. **ตารางสัญญาใกล้ราคาตลาด** พร้อมโอกาสกำไร, โอกาสเสียเงินทั้งหมด, ค่าเสื่อมเวลา และระดับความเสี่ยง
6. **ประเมินสัญญาที่คุณสนใจแบบละเอียด** พร้อมเกณฑ์ผ่าน/เตือน/ไม่ผ่าน 11 ข้อ

ผลลัพธ์แสดงในหน้าจอ และบันทึกเป็นไฟล์ HTML พร้อมกราฟ (ราคา + กรอบคาดการณ์, การกระจายผลตอบแทนรายสัปดาห์, IV smile, term structure, กราฟกำไร/ขาดทุน)

> ⚠️ นี่คือเครื่องมือสถิติประกอบการตัดสินใจ ไม่ใช่คำแนะนำการลงทุน การซื้อออปชั่นมีโอกาสเสียเงินค่าพรีเมียมทั้งหมดเสมอ

## ติดตั้ง (ครั้งเดียว)

ต้องมี **Python 3.10 ขึ้นไป** ([ดาวน์โหลด](https://www.python.org/downloads/) — บน Windows ให้ติ๊ก "Add Python to PATH")

```bash
git clone https://github.com/Resez161720/Coding-.git
cd Coding-/options-analyzer
pip install -r requirements.txt
```

ทุกคำสั่งด้านล่างให้รันในโฟลเดอร์ `options-analyzer`

## วิธีใช้

```bash
# วิเคราะห์หุ้น 1 ตัว (เลือกวันหมดอายุแรกที่ห่างอย่างน้อย 4 วันให้อัตโนมัติ)
python -m options_analyzer AAPL

# ประเมิน Call strike 250 แบบละเอียด และเปิดรายงานในเบราว์เซอร์
python -m options_analyzer AAPL --call 250 --open

# ประเมิน Put strike 240 ของวันหมดอายุที่ระบุ
python -m options_analyzer AAPL --expiry 2026-10-23 --put 240

# สรุปความน่าจะเป็นรายสัปดาห์ของหลายหุ้นพร้อมกัน
python -m options_analyzer scan AAPL NVDA TSLA MSFT SPY QQQ
```

ตัวเลือกอื่น ๆ: `--min-dte 7` (เลือกวันหมดอายุที่ไกลขึ้น), `--verbose` (แสดงผลตรวจสอบข้อมูลทุกข้อ),
`--no-html`, `--html path.html` — ดูทั้งหมดด้วย `python -m options_analyzer analyze --help`

รายงาน HTML จะอยู่ในโฟลเดอร์ `reports/`

**เวลาที่เหมาะในการรัน:** ช่วงตลาดสหรัฐเปิด (ประมาณ 20:30–03:00 น. เวลาไทย ช่วง Daylight Saving / 21:30–04:00 น. ช่วงฤดูหนาว)
เพราะจะได้ราคา bid/ask สดและ Open Interest

**ถ้ารันตอนตลาดปิด** (เช่น กลางวันเวลาไทย) Yahoo จะไม่ส่ง bid/ask และ Open Interest มา เครื่องมือจะ:
- คิดทุกอย่าง ณ เวลาปิดตลาดรอบล่าสุด (ราคาหุ้นปิด + เวลาถึงวันหมดอายุนับจากตอนปิด) เพื่อไม่ให้ IV เพี้ยนช่วงสุดสัปดาห์
- ใช้ราคาซื้อขายล่าสุดของออปชั่น **เฉพาะที่ซื้อขายช่วงท้ายตลาดและหุ้นยังอยู่ราคาใกล้ราคาปิด** (ตรวจกับราคาหุ้นรายนาที)
  ส่วน bid/ask ที่ค้างมาจากวันก่อน ๆ จะถูกตัดทิ้ง
- แสดง OI เป็น "ไม่มีข้อมูล" แทนการให้ไม่ผ่าน
- เตือนถ้ามีการประกาศงบ หรือราคานอกเวลาทำการขยับแรง หลังราคาปิดที่ใช้คำนวณ (ถ้างบออกแล้ว จะไม่แสดงการประเมินออปชั่นเลย)

## ข้อมูลถูกตรวจสอบอะไรบ้างทุกครั้งที่รัน

| หมวด | สิ่งที่ตรวจ | ถ้าไม่ผ่าน |
|---|---|---|
| ราคาย้อนหลัง | ไม่มีวันที่ซ้ำ, ไม่มีราคาหาย, ราคา > 0, High/Low ครอบคลุม Open/Close, จำนวนข้อมูลพอ, ไม่มีการกระโดดแบบแตกพาร์ที่ไม่ได้ปรับ, ข้อมูลเป็นของวันทำการล่าสุด (ใช้ปฏิทินวันหยุด NYSE) | หยุดการวิเคราะห์ทั้งหมด |
| ราคาปัจจุบัน | ตรวจไขว้ราคาจาก 2 endpoint ของ Yahoo (chart กับ options) และกับราคาปิดล่าสุด | หยุดการวิเคราะห์ |
| อัตราดอกเบี้ย / ปันผล | อยู่ในช่วงที่สมเหตุสมผล | ใช้ค่าเริ่มต้นและแจ้งเตือน |
| Option chain | มีทั้ง Call/Put, bid ≤ ask, ราคาไม่ต่ำกว่า intrinsic value, ราคาเรียงตาม strike ถูกต้อง, **Put-Call Parity** (ราคาหุ้นที่คำนวณจากออปชั่นต้องตรงกับราคาจริง), ความสดใหม่ของราคาออปชั่น, ตัด bid/ask ที่ค้างและราคาซื้อขายที่เกิดตอนหุ้นอยู่คนละราคา | ไม่แสดงการประเมินสัญญา |
| งบการเงิน | มีการประกาศงบระหว่างราคาที่ใช้คำนวณกับตอนนี้หรือไม่ (เทียบเวลาประกาศจริง ก่อนเปิด/หลังปิดตลาด) | ไม่แสดงการประเมินออปชั่น |
| การคำนวณของเครื่องมือเอง | คำนวณราคาจาก IV ย้อนกลับต้องได้ราคาตลาดเดิม, ความน่าจะเป็นอยู่ในช่วง 0–1, โอกาสกำไร ≤ โอกาส ITM, จุดคุ้มทุน/ต้นทุน/เครื่องหมาย delta ถูกต้อง | ตัดสัญญานั้นออก |

IV ทุกตัวในรายงาน **คำนวณเองจากราคาตลาดที่ผ่านการตรวจ** (ราคากลาง bid/ask หรือราคาซื้อขายช่วงท้ายตลาด) ไม่ใช้ IV ของ Yahoo
(ซึ่งมักผิดนอกเวลาตลาด) ระดับราคา (SMA, กรอบ 52 สัปดาห์, กราฟ) ใช้ราคาจริงแบบเดียวกับหน้าจอโบรกเกอร์ ส่วนสถิติผลตอบแทน
(HV, Beta, สถิติรายสัปดาห์) ใช้ราคาที่ปรับปันผลแล้ว

## วิธีอ่านผล

### ความน่าจะเป็นรายสัปดาห์ (ควร Call หรือ Put)

"สัปดาห์" = 5 วันทำการนับจากราคาล่าสุด เครื่องมือรวม 4 มุมมอง:

1. **สถิติฐาน** — ใน 10 ปีที่ผ่านมา สัปดาห์ที่ปิดบวกมีกี่ % พร้อมช่วงเชื่อมั่น 95%
2. **สถานการณ์คล้ายปัจจุบัน** — เช่น "ตอนที่ราคาอยู่เหนือ SMA50 สัปดาห์ถัดไปปิดบวกกี่ %" พร้อมจำนวนตัวอย่าง (n)
3. **โมเดลสถิติ** (logistic regression ใช้ผลตอบแทนย้อนหลัง, ระยะห่างจาก SMA, RSI, ความผันผวน, ทิศทางตลาด SPY)
   ทดสอบแบบ **walk-forward** คือทำนายทีละสัปดาห์โดยใช้เฉพาะข้อมูลก่อนหน้า (ไม่แอบดูอนาคต) แล้ววัดว่าแม่นกว่าการเดาด้วยค่าเฉลี่ยหรือไม่
   **โมเดลจะ "ผ่านการทดสอบ" เฉพาะเมื่อดีกว่าอย่างมีนัยสำคัญทางสถิติเท่านั้น**
4. **ตลาดออปชั่น** — ความน่าจะเป็นที่ตลาดตั้งราคาไว้ (risk-neutral) คำนวณจากราคา Call โดยตรง

ผลสรุปมี 5 ระดับ: `CALL` / `เอียง CALL เล็กน้อย` / `เป็นกลาง` / `เอียง PUT เล็กน้อย` / `PUT`
จะได้ `CALL` หรือ `PUT` เต็มก็ต่อเมื่อโมเดลผ่านการทดสอบเท่านั้น

> **ความจริงที่ควรรู้:** ทิศทางรายสัปดาห์ของหุ้นส่วนใหญ่ใกล้เคียงการโยนเหรียญ (ขึ้นราว 52–57% ของสัปดาห์)
> และโมเดลมักไม่ผ่านการทดสอบ เครื่องมือนี้จะบอกตรง ๆ ว่า "ไม่มีความได้เปรียบ" แทนที่จะสร้างสัญญาณที่ดูน่าเชื่อแต่ไม่จริง

### เกณฑ์ความเสี่ยงของสัญญา (มุมมองผู้ซื้อ)

| เกณฑ์ | ผ่าน | เตือน | ไม่ผ่าน | น้ำหนัก |
|---|---|---|---|---|
| Bid-Ask spread (% ของราคากลาง) | ≤ 5% | ≤ 10% | > 10% | 2 |
| Open Interest | ≥ 500 | ≥ 100 | < 100 | 1 |
| โอกาสกำไร ณ วันหมดอายุ (ตาม IV) | ≥ 40% | ≥ 25% | < 25% | 3 |
| โอกาสกำไร (จากการเคลื่อนไหวจริง 5 ปี) | ≥ 40% | ≥ 25% | < 25% | 2 |
| Theta ต่อวัน (% ของราคาออปชั่น) | ≤ 3% | ≤ 7% | > 7% | 2 |
| วันถึงหมดอายุ | ≥ 21 | 7–20 | < 7 | 2 |
| IV ÷ HV20 (ออปชั่นแพงไหม, เทียบบนฐานวันทำการเดียวกัน) | ≤ 1.10 | ≤ 1.40 | > 1.40 | 2 |
| มีประกาศงบก่อนหมดอายุ (IV crush) | ไม่มี | ยืนยันไม่ได้ | มี | 2 |
| \|Delta\| | ≥ 0.30 | 0.15–0.30 | < 0.15 | 1 |
| ทิศทางเทียบแนวโน้ม/โมเดล | ตามแนวโน้ม | สวนแนวโน้ม SMA | สวนโมเดลที่ผ่านการทดสอบ | 1 |
| คุณภาพราคา | bid/ask สด | ราคาซื้อขายล่าสุด หรือ IV สูงผิดปกติเทียบ HV60 | — | 1 |

คะแนนความเสี่ยง = ผลรวม (เตือน = 1, ไม่ผ่าน = 2) × น้ำหนัก แปลงเป็น 0–100
ระดับ: ต่ำ (< 20), ปานกลาง (< 40), สูง (< 60), สูงมาก (≥ 60)
และถ้ามีข้อ "ไม่ผ่าน" 1 ข้อ ระดับจะไม่ต่ำกว่า "ปานกลาง", 3 ข้อขึ้นไปไม่ต่ำกว่า "สูง"

### ความหมายของตัวเลขสำคัญ

- **โอกาสกำไร (IV)** — โอกาสที่ราคาหุ้น ณ วันหมดอายุจะเกินจุดคุ้มทุน ตามความผันผวนที่ตลาดตั้งราคาไว้
- **โอกาสกำไร (อดีต)** — ในอดีต 5 ปี หุ้นตัวนี้เคลื่อนไหวในจำนวนวันเท่ากันได้ไกลกว่าจุดคุ้มทุนบ่อยแค่ไหน
- **เสียหมด** — โอกาสที่ออปชั่นหมดอายุไร้ค่า
- **กรอบ ±1 SD** — ราคาจะอยู่ในกรอบนี้ราว 68% ของเวลา ตามที่ตลาดคาด
- **อดีตเคลื่อนไหวเกิน straddle** — ถ้าต่ำกว่า 45% แปลว่าออปชั่นแพงเมื่อเทียบกับการเคลื่อนไหวจริง (เสียเปรียบสำหรับผู้ซื้อ)
- **IV ÷ HV20** — มากกว่า 1 แปลว่าตลาดคาดความผันผวนสูงกว่าที่เกิดขึ้นจริงช่วงนี้ (ออปชั่นแพง)
  IV ตามมาตรฐานตลาดนับวันปฏิทิน ส่วน HV นับวันทำการ เครื่องมือจึงแปลง IV เป็นฐานวันทำการก่อนเทียบ
  (ไม่อย่างนั้นออปชั่นรายสัปดาห์จะดู "แพงขึ้น" เองทุกวันจันทร์)
- **เหลือ N วันทำการ** — นับรวมเวลาที่เหลือของวันนี้ถ้าตลาดเปิดอยู่ (เช่น 4.5 วัน)
- **การเคลื่อนไหวหลังประกาศงบ** — วัดตามเวลาประกาศจริง: งบหลังตลาดปิด = ราคาปิดวันประกาศ → ราคาปิดวันถัดไป,
  งบก่อนตลาดเปิด = ราคาปิดวันก่อน → ราคาปิดวันประกาศ (ถ้าไม่ทราบเวลา ใช้ช่วง 2 วันทำการและติดเครื่องหมาย *)

## ข้อจำกัดที่ควรรู้

- ข้อมูลจาก Yahoo Finance ฟรี **ล่าช้าประมาณ 15 นาที** ตรวจราคากับโบรกเกอร์ก่อนส่งคำสั่งทุกครั้ง
- ใช้สูตร Black-Scholes (แบบยุโรป) กับออปชั่นอเมริกัน: แม่นยำสำหรับ Call ที่ไม่มีปันผลก่อนหมดอายุ และ Put ระยะสั้นใกล้ราคาตลาด สำหรับ Put ที่ ITM ลึกจะคลาดเคลื่อนเล็กน้อย
- วันประกาศงบใช้เวลาที่แน่นอนจาก Yahoo (เวลานิวยอร์ก) ถ้ามีแค่วันที่แบบไม่มีเวลา เครื่องมือจะเผื่อไว้ 1 วัน (ยอมเตือนเกินดีกว่าพลาด)
  และแสดงว่า Yahoo ระบุวันนั้นว่า "ยืนยันแล้ว" หรือ "ประมาณการ"
- ออปชั่นของ ETF ใหญ่ (SPY, QQQ ฯลฯ) ซื้อขายถึง 16:15 ET เครื่องมือรับราคาช่วงนั้นได้โดยตรวจกับราคาหุ้นนอกเวลาทำการรายนาที
- รองรับวันที่ตลาดปิดครึ่งวัน (13:00 ET) ตามปฏิทิน NYSE
- ความน่าจะเป็นตาม IV เป็นแบบ risk-neutral (ไม่รวมแนวโน้มขาขึ้นระยะยาวของหุ้น) ส่วนแบบอดีตรวมแนวโน้มนั้นไว้แล้ว ดูทั้งสองค่าประกอบกัน
- ปิดตลาดพิเศษที่ไม่ได้ประกาศล่วงหน้า (เช่น วันไว้อาลัยแห่งชาติ) ไม่อยู่ในปฏิทิน อาจทำให้มีคำเตือนเรื่องความสดใหม่ของข้อมูล

## รันชุดทดสอบ

```bash
python -m pytest -q
```

ชุดทดสอบตรวจสูตรราคาเทียบค่าอ้างอิงในตำรา (Hull), put-call parity, IV ย้อนกลับ, Greeks เทียบการคำนวณเชิงตัวเลข,
ความน่าจะเป็นเทียบ Monte Carlo 2 ล้านรอบ, ปฏิทินวันหยุด NYSE, การจับข้อมูลเสียแบบต่าง ๆ,
ยืนยันว่าโมเดลรายสัปดาห์ไม่แอบใช้ข้อมูลอนาคต ปฏิเสธข้อมูลสุ่ม และจับรูปแบบที่ทำนายได้จริง
และกรณีที่พบจากข้อมูลจริงของ Yahoo (ราคาค้างตอนตลาดปิด, เวลาประกาศงบ, วันปิดครึ่งวัน, ออปชั่น ETF หลัง 16:00)

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `options_analyzer/data.py` | ดึงข้อมูลจาก Yahoo Finance (yfinance) |
| `options_analyzer/validation.py` | ตรวจสอบข้อมูลทุกชั้น |
| `options_analyzer/pricing.py` | Black-Scholes, Greeks, IV, ความน่าจะเป็น |
| `options_analyzer/chain.py` | จัดรูป option chain และคำนวณ IV เอง |
| `options_analyzer/stats.py` | สถิติราคา (HV, RSI, ATR, Beta, ช่วงเชื่อมั่น) |
| `options_analyzer/weekly.py` | ความน่าจะเป็นรายสัปดาห์ + โมเดลที่ทดสอบแบบ walk-forward |
| `options_analyzer/contracts.py` | เกณฑ์ความเสี่ยงของสัญญา |
| `options_analyzer/analysis.py` | ลำดับขั้นการวิเคราะห์ทั้งหมด |
| `options_analyzer/report_text.py`, `report_html.py` | รายงานภาษาไทย |
| `options_analyzer/calendar_us.py` | ปฏิทินวันทำการ/ปิดครึ่งวันของ NYSE, เวลาที่ราคาอ้างอิง และวันทำการที่เหลือ |
| `options_analyzer/earnings.py` | เวลาประกาศงบเทียบกับเวลาของราคา และการเคลื่อนไหวหลังงบ |
