# ระบบช่วยพิมพ์ Tag (Tag Print Assistant)

โปรแกรมช่วยกรอกจอเขียว AS/400 (5250) และพิมพ์ tag แทนคน จากข้อมูลที่ยิงด้วยเครื่องยิง barcode แบบพกพา
พนักงานรันเครื่องไม่ต้องมาต่อคิวที่คอมอีก คนพิมพ์ tag เดินเก็บข้อมูลเป็นรอบ แล้วให้โปรแกรมกรอก 5 หน้าจอและพิมพ์ทีละสีกระดาษ

- โปรแกรมเดิมบน AS/400 ไม่ถูกแก้ไข โปรแกรมนี้ทำงานแทนมือคนบนจอเขียวเท่านั้น
- ตรวจข้อมูลก่อนกรอกทุกครั้ง (ระบบเดิมไม่ตรวจให้) และเทียบค่าบนหน้า CONFIRM ก่อนกด Enter สุดท้าย
- เอกสารออกแบบ: [docs/superpowers/specs/2026-10-28-tag-print-assistant-design.md](docs/superpowers/specs/2026-10-28-tag-print-assistant-design.md)

## 1. ติดตั้งบนคอมเครื่องหลัก (Windows)

1. ติดตั้ง **Python 3.11 ขึ้นไป แบบ 32-bit** จาก [python.org](https://www.python.org/downloads/windows/) (เลือก "Windows installer (32-bit)")
   ตอนติดตั้งติ๊ก **Add python.exe to PATH**
   ต้องเป็น 32-bit เพราะจอเขียว iSeries Access for Windows เป็นโปรแกรม 32-bit
2. ดาวน์โหลดโปรเจกต์นี้ (ปุ่ม Code → Download ZIP) แล้วแตกไฟล์ไว้ เช่น `C:\tagbot`
3. เปิด Command Prompt ในโฟลเดอร์นั้น แล้วพิมพ์
   ```
   py -3-32 -m pip install -r requirements.txt
   ```
4. ดับเบิลคลิก `run.bat` จะมีหน้าต่างสีดำเปิดค้างไว้ (ห้ามปิดระหว่างใช้งาน) และเบราว์เซอร์จะเปิดหน้า `http://127.0.0.1:8765`

## 2. ลองโหมดทดลองก่อน

ค่าเริ่มต้นใน `config.toml` คือ `mode = "demo"` ใช้จอเขียวจำลอง ไม่แตะ AS/400 เลย เหมาะสำหรับฝึกคนพิมพ์

1. กด **ใส่ข้อมูลตัวอย่าง (โหมดทดลอง)** แล้วกด **นำเข้า**
2. ในหัวข้อ 2 กด **เริ่มพิมพ์** ของสีชมพู
3. ตอบหน้าต่างที่ถาม: ใส่กระดาษ → ตรวจหน้า CONFIRM แต่ละใบ → พิมพ์
4. ดูผลในหัวข้อ 3 แท็บ "พิมพ์แล้ววันนี้" จะเห็นเลข Lot ใหม่ของแต่ละใบ

## 3. ใส่ข้อมูลจริง

แก้ไฟล์ในโฟลเดอร์ `data` ด้วย Excel แล้วบันทึกเป็น **CSV UTF-8** จากนั้นกด **โหลดตารางข้อมูลใหม่** ที่ท้ายหน้าเว็บ

**`data/machines.csv`** (จำเป็น) เครื่องจักร 1 แถวต่อ 1 เครื่อง

| คอลัมน์ | ความหมาย | ตัวอย่าง |
|---|---|---|
| machine | รหัสเครื่อง ตามที่กรอกช่อง M/C No. | A2 |
| name | ชื่อที่แสดงบนการ์ด | Press 2 |
| color | สีกระดาษปกติของเครื่องนี้ | ชมพู |
| multi_type | ทำได้หลายประเภทงานหรือไม่ (Y/N) ถ้า Y ต้องเลือกสีต่อใบสั่งงาน | N |
| speed | ค่าที่กรอกช่อง M/C Speed (ตัวเลข) | 350 |
| action | ค่าที่กรอกช่อง Action (เว้นว่างถ้าเครื่องนี้ไม่ต้องกรอก) | X04 |
| route | ลำดับบนเส้นทางเดิน (โปรแกรมพิมพ์ตามลำดับนี้) | 2 |

**`data/operators.csv`** รหัสพนักงานและชื่อ (ถ้าไม่มีไฟล์ จะไม่ตรวจรหัสพนักงาน)
**`data/carts.csv`** เลขรถเข็น (ถ้าไม่มีไฟล์ จะไม่ตรวจเลขรถเข็น)

ใน `config.toml` ต้องแก้ให้ตรงกับโรงงาน:
- `[shifts]` เวลาเริ่มของแต่ละกะ
- `colors` ชื่อสีกระดาษที่ใช้
- `[process_colors]` (ไม่บังคับ) รหัส process ที่ต้องใช้สีเฉพาะ

## 4. การ์ด barcode

กดลิงก์ **พิมพ์การ์ด barcode** ที่ท้ายหน้าเว็บ แล้วกด Ctrl+P

- **ป้ายเครื่องจักร** ติดที่เครื่อง, **ป้ายรถเข็น** ติดที่รถเข็น
- **การ์ดพนักงาน** เสียบไว้ที่เครื่องตอนต้นกะ
- **การ์ดคำสั่งและตัวเลข** คนพิมพ์พกติดตัว (แนะนำให้เคลือบพลาสติก)
- การ์ดดายใช้ของเดิมได้ ถ้ายิงแล้วได้ข้อความรูปแบบ `DIE.4` (ถ้าไม่ใช่ ให้แก้ `die` ในหมวด `[barcodes]` ของ `config.toml`)

## 5. ตั้งค่าเครื่องยิง barcode แบบพกพา

- โหมด **เก็บข้อมูลในเครื่อง** (Inventory / Batch mode)
- ให้ส่ง **Enter** ต่อท้ายทุก barcode
- ต้องอ่าน Code 128 และ Code 39 ได้ (แนะนำรุ่นที่อ่าน QR ได้ด้วย)
- ตอนส่งข้อมูลเข้าคอม: คลิกในช่องของหัวข้อ 1 ก่อน แล้วสั่งส่งข้อมูลจากเครื่องยิง
- ถ้าแป้นพิมพ์ของ Windows เป็นภาษาไทยอยู่ โปรแกรมแปลงกลับให้เอง แต่ตั้งเป็นภาษาอังกฤษไว้จะดีกว่า

**ลำดับการยิงที่หน้าเครื่องจักร**
1. ป้ายเครื่อง (ทุกครั้งที่มาถึงเครื่องใหม่)
2. ใบสั่งงาน
3. ป้ายวัตถุดิบ D/O และ Coil
4. การ์ดดาย
5. การ์ดพนักงาน
6. ป้ายรถเข็น แล้ว **เต็มตะกร้า** (หรือ ตัวเลขทีละหลัก แล้ว **จบ**)
7. ถ้ามี NG: **NG** → ตัวเลข → **จบ**

ตะกร้าถัดไปของงานเดิม ยิงแค่ข้อ 6 ยิงผิดให้ยิง **ยกเลิกรายการล่าสุด**

## 6. วันแรกกับจอเขียวจริง

1. เปิดจอเขียว (session A) ไปที่หน้า **DEP012G1 (MFG ORDER SPLIT LOT)**
2. แก้ `config.toml`: `mode = "pcomm"` และคงค่า `confirm_before_final_enter = true` ไว้
3. เปิด `run.bat` นำเข้าข้อมูลแค่ 1 ตะกร้า แล้วกดเริ่มพิมพ์ ดูจอเขียวไปพร้อมกัน
4. ทุกใบจะมีหน้าต่างให้ตรวจหน้า CONFIRM ก่อนพิมพ์ ถ้าค่าไม่ถูกให้กด **ไม่พิมพ์ (หยุด)**
5. ถ้าโปรแกรมหยุดหรือหาช่องไม่เจอ: กด **บันทึกหน้าจอเขียว** แล้วส่งไฟล์ในโฟลเดอร์ `dumps` กับ `logs/tagbot.log` ให้ผู้พัฒนา
6. เริ่มจาก 3–5 เครื่องประมาณ 1 สัปดาห์ เมื่อมั่นใจแล้วค่อยขยาย และค่อยปิดการยืนยันทีละใบ

ระหว่างที่โปรแกรมทำงาน **ห้ามพิมพ์หรือคลิกบนจอเขียว** และเปิดโปรแกรมนี้ได้ทีละหน้าต่างเท่านั้น

## 7. สถานะของรายการ

| สถานะ | ความหมาย | ทำอะไรต่อ |
|---|---|---|
| รอพิมพ์ | ยังไม่เริ่ม | ถ้ามีหมายเหตุสีส้ม ให้กด "แก้ไข" |
| ไม่สำเร็จ | หยุดก่อนกด F5 ยังไม่มีอะไรถูกบันทึกใน AS/400 | แก้ไข แล้วกด "ลองใหม่" |
| ต้องตรวจบนจอเขียว | หยุดหลังกด F5 (lot ใหม่ถูกสร้างแล้ว) โปรแกรมหยุดทั้งชุด | ทำต่อเองบนจอเขียวให้เสร็จ แล้วกด "ทำเองบนจอเขียวแล้ว" |
| พิมพ์แล้ว | พิมพ์ tag แล้ว | เดินส่ง tag |

## 8. เรื่องที่ต้องยืนยันก่อนใช้งานจริง

1. กรณีมี NG: LOT M/O QTY = OK + NG ใช่หรือไม่ (ถ้าไม่ใช่ ตั้ง `lot_qty_includes_ng = false`)
2. เวลาเริ่มของแต่ละกะ
3. barcode ของการ์ดดายที่มีอยู่ ยิงแล้วได้ `DIE.4` หรือรูปแบบอื่น
4. หลังกด Enter หน้า CONFIRM จอกลับไปหน้า DEP012G1 เองหรือไม่ (ถ้าต้องกดปุ่ม ให้ตั้ง `home_keys`)
5. ตำแหน่งช่องบนจอจริง (ตรวจจากไฟล์ "บันทึกหน้าจอเขียว" ในวันแรก)
